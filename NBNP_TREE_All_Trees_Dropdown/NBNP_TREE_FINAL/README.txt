NBNP TREE - Professional Tree Directory Website

Features:
- Main homepage with professional botanical design
- No 66 tree cards on the homepage
- Tree Directory dropdown in the top navigation
- Search all 66 trees by common name, botanical name, family or Tamil name
- Select any tree to open tree.html?id=NUMBER
- Dedicated information page for every tree
- English and Tamil information
- No QR code

Run in VS Code:
1. Extract the ZIP.
2. Open the NBNP_TREE folder in VS Code.
3. Install Live Server.
4. Right-click index.html -> Open with Live Server.

The 66 tree records are populated from the supplied Tree Sign board Word document.
