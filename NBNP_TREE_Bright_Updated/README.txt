NBNP TREE - Professional Tree Website

Files:
- index.html   -> Main homepage
- tree.html    -> Reusable tree information page
- style.css    -> Bright botanical design with responsive layout
- data.js      -> All 66 tree records extracted from the supplied Word document
- app.js       -> Homepage search, family filter and click/tap Tree Directory dropdown with searchable tree list
- tree.js      -> Loads the selected tree information

How to run in VS Code:
1. Open the NBNP_TREE folder in VS Code.
2. Install the "Live Server" extension.
3. Right-click index.html -> Open with Live Server.
4. Click/tap "Tree Directory" in the top navigation and search the tree list.
5. Search/select any tree. It opens tree.html?id=NUMBER.
6. You can also search the collection cards.

Important:
- QR codes were intentionally removed.
- The medicinal/traditional information is preserved from the supplied Word document.
- The background uses online Unsplash photographs. If you want an offline website, replace the background URLs in style.css with local images in the images folder.
