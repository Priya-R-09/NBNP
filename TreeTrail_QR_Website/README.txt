TREE TRAIL — QR TREE ENCYCLOPEDIA

Files:
- index.html      Main creative/professional landing page
- style.css       Main design
- trees/          66 individual tree profile pages

QR setup:
1. Upload this folder to Netlify, Vercel, GitHub Pages, or another web host.
2. Each tree page has its own URL, for example:
   /trees/01-sago-palm.html
3. Generate one QR code per tree using that tree page URL.
4. Print the QR beside the matching tree.
5. When visitors scan it, they open that tree's profile.
6. The "Back to collection" link takes them to the main page.

The tree profile content is generated from the uploaded
"Tree Sign board with QR Cod 2025-2026.docx".
